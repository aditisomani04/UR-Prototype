# Driver's Delight

Connect to github repo: https://github.com/aditisomani04/UR-Prototype

Create a mobile application prototype that supports equipment delivery and pickup workflows for a driver traveling from a branch to multiple customer stops:

The prototype should include the following core concepts:

Login Basic login screen for a driver.

Trips Ability to view multiple trips, such as Trip 1 and Trip 2. Each trip should include multiple stops.

Stops Each stop should show whether it is a delivery or pickup. Each stop should include: Customer name Customer address Equipment details

Delivery / Pickup Workflow Driver should be able to mark a stop as completed. Driver should be able to see pending and completed stops.

Return to Branch Include a final step or status showing the driver returning to the branch after completing all stops.   Focus on usability, workflow clarity, and how a driver would understand the trip, stop, delivery, and pickup process.
